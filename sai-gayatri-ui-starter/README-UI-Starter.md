SAI GAYATRI INDUSTRIES — UI Starter

This is a React + TypeScript starter scaffold for the SAI GAYATRI INDUSTRIES front-end UI.

Key features:
- Vite + React + TypeScript
- Tailwind CSS (utility-first)
- App shell with Sidebar, Topbar, BottomNav
- Pages: Home, Sales, New Sale (full UI-only form), Inventory, Reports
- No sample data; all sections intentionally show empty states

How to run:
1. cd sai-gayatri-ui-starter
2. npm install
3. npm run dev

Notes:
- This starter implements the UI/UX and form structure only. No backend or persistence is included.
- The New Sale form supports up to 8 dynamic product rows and performs client-side calculations.

Design & tokens are implemented via Tailwind config and src/index.css.
